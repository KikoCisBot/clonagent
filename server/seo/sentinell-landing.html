Proceso

Así funciona Sentinell

Sin agentes instalados, sin acceso a tu servidor. Escaneamos desde fuera, como lo haría un atacante.

🔍

Escaneamos

Analizamos tu dominio y servicios online con más de 100 checks automatizados: cabeceras HTTP, archivos expuestos, versiones de software, configuraciones incorrectas y CVEs conocidos.

⚡

Encontramos problemas

Clasificamos los hallazgos por gravedad. Desde configuraciones menores hasta vulnerabilidades críticas que pueden exponer datos de tus clientes o comprometer tu servidor.

🔔

Te avisamos

Recibes un informe claro con los problemas encontrados y pasos para resolverlos. Con el plan Pro, también podemos encargarnos de los arreglos por ti.

Cobertura

Qué detectamos

Vulnerabilidades reales que los atacantes buscan activamente cada día.

📂

Archivos de configuración expuestos

Archivos sensibles accesibles públicamente que pueden revelar contraseñas de base de datos, claves API y credenciales de servidor.

wp-config.php .env .htaccess config.json .git/
💀

Software obsoleto con CVEs conocidos

Versiones de WordPress, plugins, PHP, servidores web y librerías con vulnerabilidades públicamente documentadas y exploits activos.

WordPress EOL PHP < 8.1 Apache CVEs Plugin vulns
🔓

Configuraciones erróneas y fugas de datos

Cabeceras HTTP mal configuradas, CORS permisivos, directorios listables, formularios sin protección CSRF y endpoints de admin expuestos.

Open redirects Missing CSP CORS wildcard Directory listing
Para quién

Hecho para quien construye online

No hace falta ser una empresa grande para necesitar seguridad. Cualquier servicio online es un objetivo.

🛒

Tiendas WooCommerce

Proteges los datos de pago y envío de tus clientes. Una brecha puede costarte multas RGPD y la confianza de tu audiencia.

🚀

SaaS y proyectos indie

Tu API, tu panel de admin, tu webhook de Stripe — cada endpoint es una superficie de ataque. Monitorízalos todos.

🌐

Cualquier servicio online

Portales corporativos, intranets expuestas, herramientas internas, blogs con formularios de contacto — si está en internet, necesita vigilancia.
